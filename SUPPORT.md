# Request help with your deployment

English · [Français](SUPPORT-fr.md)

[Documentation home](README.md)

For the first setup checks, start with the [quick start](QUICKSTART.md).

## Choose the right starting point

| Need | Starting point |
|---|---|
| Suspected image packaging or initialization problem; documentation correction | Contact Cotechnoe at [support@cotechnoe.com](mailto:support@cotechnoe.com), or use the public documentation issue tracker below without sensitive data. |
| Azure provisioning, access, infrastructure or billing problem | Your organization's Azure administrator and its authorized Microsoft support channel. |
| Realm, users, authentication policy or application integration | Your Keycloak administrator and application owner; consult the [official administration guide](https://www.keycloak.org/docs/latest/server_admin/index.html). |
| An end user's application sign-in problem | Your organization's help desk or application owner, not a public infrastructure issue containing account details. |

This routing guidance does not establish a contractual support entitlement. If several layers are involved, keep the deployment owner engaged rather than assuming one supplier operates the entire service.

## Report a non-sensitive image or documentation problem

1. Use [Troubleshoot and request help](docs/07-troubleshoot-and-get-support.md) to prepare a minimal report.
2. Review and remove secrets, personal data and confidential infrastructure details.
3. [Open an issue in the public documentation repository](https://github.com/Cotechnoe/keycloak-azure-marketplace-docs/issues).

Public issues are visible to everyone. Do not attach credential files, database configuration, tokens, private keys, session cookies or full logs.

For a private initial request, email [support@cotechnoe.com](mailto:support@cotechnoe.com) with a minimal description, not secrets or diagnostic archives. If investigation requires sensitive information, agree on a secure transfer method with the recipient first. No private diagnostic-upload facility is established by this documentation.

Read the [privacy notice](PRIVACY.md) before sharing information.
